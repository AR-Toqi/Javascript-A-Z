# 🧠 JavaScript Basic to Advance

A complete **JavaScript learning repository** that covers everything from the **fundamentals** to **advanced concepts** through real-world projects and hands-on exercises.
This repository is designed to help learners understand how JavaScript truly works behind the scenes and how to apply it in practical scenarios.

---

## 📘 Overview

This repo includes a complete journey through JavaScript — starting from core programming concepts and advancing into DOM manipulation, object-oriented programming (OOP), asynchronous JavaScript, and complex project structures.

Each folder represents a key milestone in the learning path, complete with well-documented code and projects that demonstrate real-world use cases.

---

## 🧩 Projects Included
<ul>
Pig Game (DOM Manipulation)

</ul>

## ⚙️ Technologies Used

* **JavaScript (ES6+)**

* **CSS3**
* **DOM API**

* **Async JavaScript** (Promises, Fetch API, Async/Await)
* **OOP and Functional Programming**

## 🚀 Learning Goals

* Strengthen your understanding of **JavaScript fundamentals**
* Learn **modern ES6+ features**
